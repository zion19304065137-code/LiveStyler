# 暖场海报提示词与实拍底图修正

暖场定位为独立完整活动海报：主题、品牌风格、主视觉和必要文案重新构图；不沿用直播贴片清单。不默认LIVE、空白卖点框、价格、售后承诺、聊天框、真人或PPT窗口。未知事实省略；用户本次明确要求优先。

公司API真实图像输入共5次：美妆电商、科技发布会、年会、教育培训各一次，课程再测一次。电商输出商品静物品牌海报，无空白卖点框和参考图服务标签；发布会为AI主题意象；年会为蓝金庆典意象。课程首轮仍保留了参考讲师，因此强化禁止默认人物的规则，复测变为笔记本和AI办公主题意象。单次6.8–9.6秒。仅为方案调用，不是生产生图API端到端验收。

本地产品测试验证暖场方案规则与图像请求：引用当前品牌上下文、完整不透明海报、无默认直播模块、无黑边补块；只在确认后生图。原封面与透明包装不变。

通过内置图像生成工具制作发布会、年会满版实拍原画，替换默认下移原画以留白的旧策略。横竖合成复核发现第一版年会横屏标题仍遮挡人物，再单独修正横屏原画；竖屏采用单独来源。测试样例不应声称真实活动照片。

未覆盖：真实生图服务输出的完整视觉质量、真实浏览器交互。旧用户上传照片和自定义移动不自动复位；只恢复匹配旧模板默认下移且仍锁定的原画。
